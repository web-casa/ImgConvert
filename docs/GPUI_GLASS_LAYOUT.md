# GPUI 清透玻璃 2.0 布局

2026-10-22 用户在五个方向中选定 B“清透玻璃 2.0”，并要求单独的浅色版；它取代 [卡片分栏布局](GPUI_CARD_LAYOUT.md)。设计画布（私有）：https://claude.ai/artifact/3ZFD9o2fZWgdigZzUy5nM8 ，页面“B 清透玻璃 · 完整稿”含空队列、导入中、完成、隐私与偏好、窄窗口和两个对话框。用户此前“暂缓视觉重排”的决定由这次选定解除；G2 非视觉验收仍按 `GPUI_G2_ACCEPTANCE.md` 执行。

## 结构

- 窗口：柔光背景 + 标题行 + 两块玻璃面板。标题行左侧为品牌，右侧是一条玻璃胶囊，放窗口级命令（插件诊断、检查更新、隐私、开源许可、语言、外观）。
- 队列面板是主区域；底部是悬浮操作胶囊（输出文件夹、状态与进度、批量情景、开始/取消）。胶囊在正常布局中位于面板底部，队列列表在它上方结束，没有行被遮挡，也不需要遮挡补偿。
- 设置面板固定在尾侧。两块面板始终可见，因此删除了原来的“队列 / 转换 / 设置”导航栏和操作栏里的设置齿轮；“外观”命令仍展开并聚焦现有外观选项。
- 主按钮只有“开始转换”；取消批量保留已完成的输出，不是破坏性操作，用默认按钮而不是危险色。

## 主题与材质

- 颜色只在主题层：Kit 主题文件 `themes/imgconvert-glass.json`（浅色 Clear / 深色 Obsidian）和 `theme.rs` 的 `GlassTokens`。业务代码通过 `GlassStyled`（`glass_panel` / `glass_bar` / `glass_capsule` / `glass_well`）和 `ActiveGlass` 取值，不写裸色值。
- 浅色：底 `#e8ebf1`，白、淡粉、淡蓝、薄荷四团光斑；面板 62% 白、近白描边、顶部内高光，并加一圈 4% 深色外轮廓（浅背景上只有白描边分不出面板边界）。深色沿用黑曜石底与蓝/粉/青三团光斑。
- 主按钮为左到右渐变（浅 `#1670f0 → #0a5ce0`，深 `#5ac8fa → #2b93ff`），同时写入 `primary` 与 `button_primary`；每个色标上的前景对比度不低于 4.5:1。
- 不做背景模糊：锁定的 gpui-pre 0.3.8 没有元素级 backdrop blur，悬浮胶囊因此保持 96% 不透明。若将来评估模糊，只替换这几个 helper，不改业务代码；评估结论见 2026-10-22 对 sonorahq/gpui、gpui-fusion、bezel 等的核实（不切换 GPUI 分支）。

## 设置标签页与外观（第 2 片）

- 设置面板顶部是“格式 / 输出 / 处理 / 隐私”分段标签；各标签页内的分区以小标题 + 浅色底板呈现，不再折叠。格式页：场景预设、目标格式卡片、质量、保存与管理预设、压缩策略、格式参数；输出页：输出行为、缓存；处理页：批量尺寸、目标体积、PDF 转图片、色彩管理；隐私页：隐私元数据。
- 开始前会被拒绝的配置（目标体积不适用、PDF 页面范围无效）在对应分区标题和所在标签上都带警告标记，从任何标签页都能发现。
- Kit 0.7.1 的 `Tab` 不能获得键盘焦点，所以每个标签是带 Tab 角色与选中状态的按钮；目标格式卡片是一个单选组：组本身是一个 Tab 停靠点，方向键 / Home / End 切换，点击直接选择，组的值沿用原选择框的“格式 · 来源”写法。
- 主题与减少动画移出设置表单，放在标题行“外观”命令的弹出层里（主题三段单选 + 开关），直接写入设置记录；Escape 关闭弹出层。

## 队列行与状态（第 3 片）

- 队列标题行：标题 + 数量胶囊，右侧是重置格式、清空（低强调）和添加文件 / 文件夹 / 粘贴；窄时换行而不是裁切。
- 队列行（4.25rem）：缩略图占两行高；第一行是文件名与结果，第二行是元信息与“全局 · 格式”胶囊；最右侧固定一列是存储情景（完成后）、前后对比、移除三个图标按钮。三个命令始终可见、可用键盘到达并有无障碍名称；没有采用设计稿的“…”菜单，以免常用的对比多一次点击。在 760px 窗口下单行布局会挤掉文件名，因此保留两行。
- 结果列是紧凑形式：完成显示输出大小与变化（“节省 81%”或“增加 29%”，变大不着绿色；大小相同写“大小不变”，不到 1% 写“不到 1%”，不四舍五入成 0%）、有告警时标出；结果列可随文字列收缩，长原因截断而不压到命令列；跳过 / 失败显示状态与原因并截断，完整文字是该列的无障碍值和提示，未改变。
- 空队列：整个队列区域是拖放目标，虚线框表明这一点；中间是三张叠放的玻璃卡片插画、“还没有图片”与说明、三个导入按钮和支持的格式胶囊。导入中的提示是带转圈的横幅，导入完成的摘要是一行弱文字。
- 完成后操作胶囊显示“完成 N（· 跳过 / 失败，非零时）· 节省 X”，节省量只统计本批任务中“这次写出了全部输出”的完成行（`ItemStatus::Done::complete`；上一批留下的行和部分页面被跳过的 PDF 不计），求和溢出或输出没有净减少时不写节省；输出文件夹只显示最后两级目录，完整路径在提示和无障碍名称中。设计稿里的“打开输出文件夹”需要新的平台接口，本片不做。

## 回归检查

真实组件测试在 760×480、1000×640、1280×800 三种尺寸下覆盖明暗 × 中英：队列在操作胶囊上方结束、胶囊在队列面板内、设置面板在尾侧且不越出窗口、导入与开始按钮可见；“外观”弹出层在窗口内打开、Escape 关闭，主题与减少动画写回设置记录；运行中的批次在使用该命令后保持不变；每个分区可从其标签页到达，标签与格式卡片暴露 Tab / 单选角色和选中状态，格式组支持方向键。视觉仍以实际窗口截图为准。
