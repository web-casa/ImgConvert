# GPUI 卡片分栏设计

2026-10-19 用户以本机 `~/jietu/001.png` 的“卡片分栏”方案指定设计方向。参考图快照保存在忽略目录 `artifacts/reviews/g2-native-2026-10-19/design-reference-cards.png`。

## 布局与行为

- 左侧为同一工作区的区域快捷入口：队列恢复主区域焦点，转换跳到转换参数，设置展开并聚焦外观选项。不是三个新业务页面；队列、参数和运行中的批次由原有实体持续持有。窄窗口仅收起导航文字，保留图标、提示和无障碍名称。
- 中部导入卡片提供添加文件、添加文件夹和粘贴，拖放仍作用于原有队列区域。文件夹入口使用仅选目录的原生选择器，递归扫描、取消和反馈继续复用现有导入流程。导入格式标识在后台读取 backend capability matrix，首次读取等待启动时的 helper 恢复完成（失败也释放等待），手动 helper 路径变更会重新读取，以 revision 丢弃过期结果，不宣称截图中的所有格式均可输出。
- 右侧保留全部转换选项；预设和目标格式放在顶部，预设管理仍在原分组，Select 状态只有一个可见实例。预览、告警、动画/精度保护、缓存和输出安全策略沿用。
- 底栏为正常布局中的固定区域，展示输出目录、状态、设置入口与开始/取消。内容区在底栏上方结束，删除原悬浮栏的遮挡补偿。空队列、导入中和运行中继续由真实模型决定按钮状态。

## 系统与验证边界

沿用 GPUI Kit 0.7.1，组件负责交互，产品主题负责颜色与圆角；同时检查明暗主题、中英文字和最小窗口。原生窗口装饰和系统选择器继续使用平台行为。新增布局不代表 G2 收口，IME、VoiceOver 和沙盒完整验收仍按 `GPUI_G2_ACCEPTANCE.md` 执行。

实现分支 `feat/gpui-card-layout` 基于尚未合并的 PR #34，单独 review；不得为重排自动合并上一 PR。最终截图、review 和 CI 记录补入对应 PR。

## 回归检查

真实组件测试覆盖三种尺寸下明暗×中英的 12 组组合、PNG 禁用质量时的格式焦点、外观聚焦及手动滚动保持、root 焦点返回、非空运行中批次和设置值保持。原有导入、取消、剪贴板、输出安全、告警、对话框及许可测试继续执行。视觉仍需用实际窗口截图补充，不能以坐标断言代替。

本地全量 GPUI 94 项测试通过（含 33 项真实组件 UI 测试）；Clippy all-targets 零警告。新增启动恢复测试覆盖成功、失败、无手动 helper 及重复初始化；通过临时恢复 absolute 底栏确认布局断言会失败，恢复正常布局后通过。
