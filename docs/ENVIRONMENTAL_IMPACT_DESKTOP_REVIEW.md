# 桌面环保功能实施与复核

日期：2026-09-06。ENV-005 本地实现记录。桌面版本仍为 0.3.1；没有构建正式安装包、部署、提交商店或公开 Release。Linux 原生开发构建已通过本轮验收；跨平台与正式安装包验收仍待完成。

## 实现

- 单文件完成后显示实际字节变化；批量按同一假设计算净额，变大的文件抵消变小的文件。失败、取消及不具备资格的结果不参与估算。
- 默认本机/未知场景，只显示字节事实。用户主动选择云存储后，才使用共享 environmental-impact v1 模型估算。
- 支持假设替换、自行确认替换和保留原图；保留原图不产生正向估算。天数、副本数和方法边界可见，不宣称已经节电、净减排或碳抵消。
- 中英文界面及离线方法说明。参数只在面板内存中存在，关闭、移除结果或重试后清理，不新增网络请求、持久化、文件扫描或删除行为。

## 证据与比较资格

Rust 结果新增 `environmentComparable`，依据本次已读取的字节与已有探测结果计算，普通结果与缓存命中均携带。前端要求路径匹配、正的安全整数字节数、单输出且没有跳过输出；旧后端缺少资格字段时保守排除。

JPEG、BMP 和已通过无动画探测的 WebP 可比较。PNG 额外进行有界块扫描，遇到动画控制块、截断、尾随数据或超出预算即排除。PDF、SVG、GIF 及未确认序列状态的 AVIF/HEIC 输入不参与环境估算，仍可显示可用的字节变化。AVIF/HEIC 的排除是本阶段限制，不影响既有转换功能。

## Review 与修复

| 风险 | 处理 |
| --- | --- |
| 从格式名猜测静态输入，把丢帧算作收益 | 原生字节证据、PNG 动画块检查，未确认序列类型排除 |
| 大小读取失败得到 0，显示完全节省 | 拒绝零值、非安全整数及路径不匹配结果 |
| 多页文档或部分跳过输出被当成单张比较 | 原生 PDF 标记 false，前端独立检查输出数量 |
| 批量忽略变大输出或重复累计历史任务 | 从当前完成队列推导净额，重试清理旧证据 |
| 翻译键与审计不一致 | 改用显式翻译键，移除未使用键 |
| 关闭后残留云存储参数 | 关闭重置，中英文交互回归覆盖 |
| 用户自述替换被当作已验证减排 | 保留假设边界，不读盘确认或删除文件 |

## 后续原生验收（2026-09-06）

本轮通过 `pnpm e2e:desktop:build` 构建带既有测试 seed 的 debug 应用，并通过 `pnpm e2e:desktop:run` 在 Xvfb + Tauri Driver + WebKitGTK 中运行真实 Rust 后端与 IPC。没有新增产品测试接口。

原生 3 项测试通过：PNG/PDF 预览与转换；按实际磁盘字节验证 PNG 节省量、PDF 排除、批量资格、原图保留状态及中英文切换；重试因已有输出被跳过时清除旧环保结果。PNG 实测 2527 → 466 字节，界面显示 2.01 KiB，图片和 PDF 源字节在场景交互前后保持一致。

Review 修复两处测试基础设施问题：

- 配置已隔离，但缓存与应用数据仍可能写入用户目录；现在一并放入会话临时目录。
- WDIO 启动进程和工作进程重复创建临时文件，导致工作进程文件残留；现在复用启动进程的目录，只有创建者负责清理。

新增目录所有权回归测试验证复用、隔离、工作进程不提前删除和创建者最终清理。`pnpm test` 现为 28 文件、211 项通过，Lint 与类型检查通过。检查了原生中英文截图，保存在本地忽略目录 `artifacts/desktop-e2e/`。

环境日志存在虚拟显示环境缺少 a11y bus，以及 WebDriver 自动重试的过期元素/暂不可交互警告，最终测试通过；本轮不声明读屏验收完成。当时缓存命中专门回归尚未完成，现已由下述 2026-09-07 专项补齐；正式 Linux 安装包及 macOS/Windows 原生运行仍需验证。

## 缓存专项复核（2026-09-07）

新增 Linux Rust 集成回归，使用独立子进程及临时 XDG 缓存目录，结束后清理，不修改并行测试的全局环境。没有新增产品 IPC 或缓存标志。

- 正常缓存命中：保持原输出文件打开，通过 inode 未替换证明没有重新编码写盘，并验证当前输入/输出字节及 camelCase 序列化字段。
- 输出同长度损坏：修改一个字节，证明哈希检查使缓存失效、重新编码修复输出，资格与输出大小仍正确。
- 源文件变化：插入有效 PNG 文本块，确认重新编码、输入字节更新，不沿用旧结果统计。
- SVG 缓存命中：确认确实复用输出，但仍不具有环境比较资格。

本轮验证：`cargo test --manifest-path src-tauri/Cargo.toml` 通过 193 项库测试及 4 项主程序测试；`cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`、Rust 格式检查及 `pnpm docs:check` 均通过。

本轮 review 未发现需要修改缓存产品逻辑的缺陷；补齐的是先前缺少的转换与缓存端到端回归，避免仅凭两次输出相同就宣称缓存命中。此测试仅覆盖 Linux 后端，不代表 macOS/Windows 或缓存命中的原生界面专项验收。
