# 环保功能 Web 实施与复核

日期：2026-09-06。范围：ENV-001–003 的本地实现。官网/Web 尚未部署；扩展和桌面面板仍待接入。本次不修改 Chrome/Edge 0.3.3 候选安装包，不执行商店提交或公开发布。

## 已实现

- 官网 `/environment/`、`/en/environment/`：存储与设备生命周期说明、个人云存储假设计算器、全球每日每人 1 MB 的累计情景、方法与原始资料链接。
- 页面正文与静态 HTML 从同一份双语内容生成，禁用 JavaScript 仍能读取科学说明、限制及来源；首页页脚、canonical、hreflang、sitemap 和 Web 发布必需路由同步。
- Web 单结果与批量净减少区域新增可展开面板。默认本地/未知存储，仅展示字节事实；主动选择云存储假设后才估算。原图保留时不展示正向估算，自述替换仍明确标为估算。
- 保留天数、副本数与原图状态在各面板中独立、仅驻留内存。关闭重置，清空队列销毁面板；批量按合资格结果的输入输出净差计算，较大输出抵扣较小输出，显示其他已完成但不合资格的数量。
- 计算复用 `@imgconvert/environmental-impact`，仅增加有界参数适配和有意义位数的单位格式化。科学系数、公式及模型版本未修改。没有新增网络接口、遥测、权限或图片扫描/删除行为。

## 口径复核

实际可验证的是字节差，不是磁盘已释放、已经节电或实际减排。环境数字使用平均云容量分摊模型：不反映本地硬盘，也不反映边际电力变化。假设区间不是置信区间，不含转换耗电、网络、硬件制造、处置和反弹效应；电子废弃物资料用于科普，不计入每张图片的碳信用。

全球情景固定 ITU 2025 年约 60 亿网民与十进制 1 MB/人/天；参与比例、天数和副本可调。按每日批次分别累计保留时间。默认 365 天、100% 参与、1 副本：期末容量差 2.19 EB，运行电量分摊约 6.88–13.7 GWh。这个数字不是 ImgConvert 或全球用户已经实现的节电量。

## 复核中修复

1. Web 严格可选属性类型不接受显式 `undefined`；结果面板现明确接受不合资格测量，并解释排除原因。
2. 官网旧 `.hero` 全局网格影响新页面，导致标题过度换行；改为专用样式类，并复核桌面与 320 px 页面。
3. 为下拉框明确无障碍名称；浏览器用角色及名称定位，避免把原生包裹标签中的选项文本误当标签名称。各循环增加稳定键，满足 Svelte lint。
4. 深色模式下，面板可能继承队列卡片的浅背景；改为使用明确的主题前景和背景令牌，减少说明文字对父卡片样式的依赖。
5. 增补负净差、混合资格、重复读取/下载状态及清空队列回归，防止把正向减少简单相加。没有引入跨面板减碳累计计数；批量面板明确说明其统一假设独立于单文件面板。

## 尚未完成的发布与后续范围
