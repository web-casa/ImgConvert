# ImgConvert brand

The mark is a disc split down the middle: the left half is the image as a bitmap (square pixels quantised from the same gradient), the right half is the smooth image. It is the "pixel half-circle" chosen on 2026-10-23 for the Clear Glass 2.0 interface.

## Masters

All masters are generated by `generate.py` (no dependencies beyond Python 3) and are the only sources for every raster icon in the repository. Edit the script, never the SVGs.

| File                   | Use                                                                |
| ---------------------- | ------------------------------------------------------------------ |
| `logo.svg`             | Full-bleed tile: Windows, Linux, web, 48 px and up                 |
| `logo-small.svg`       | Full-bleed tile with coarser pixels: 32 px and below               |
| `logo-macos.svg`       | 824 px tile on the 1024 px macOS grid with a soft shadow           |
| `logo-macos-small.svg` | The macOS frame with coarser pixels: 48 px and below               |
| `logo-mark.svg`        | The mark without a tile                                            |
| `logo-mark-small.svg`  | The mark at title-bar size (about 28 px); drawn in the GPUI header |

## Regenerating

```bash
python3 assets/brand/generate.py assets/brand
```

Rasterise with resvg 0.48 (the version the converter already uses), for example `resvg logo.svg out.png -w 512 -h 512`, then:

| Output                                                                                                                                               | Master and sizes                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `src-tauri/icons/128x128.png`, `128x128@2x.png` (256), `icon.png` (512), `app-icon-source.png` (1024), `Square{71,89,107,142,150,284,310}x…Logo.png` | `logo.svg`                                                                                                             |
| `src-tauri/icons/32x32.png`, `Square30x30Logo.png`, `Square44x44Logo.png`, `StoreLogo.png` (50), `public/favicon.png` (32)                           | `logo-small.svg`                                                                                                       |
| `src-tauri/icons/icon.ico`                                                                                                                           | 16, 24, 32 from `logo-small.svg`; 48, 64, 128, 256 from `logo.svg` (`magick a.png b.png … icon.ico`)                   |
| `src-tauri/icons/icon.icns`                                                                                                                          | 16, 32, 48 from `logo-macos-small.svg`; 128, 256, 512, 1024 from `logo-macos.svg` (`png2icns`, or `iconutil` on macOS) |
| `src/lib/assets/app-icon.png`, `docs-site/public/app-icon.png` (256), `website/public/images/product/app-icon.png` (128)                             | `logo.svg`                                                                                                             |

The GPUI header embeds `logo-mark-small.svg` directly. When GPUI packaging replaces the Tauri bundle (migration stage 5), its icons come from these masters as well.
