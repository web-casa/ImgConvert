01 / EN

English privacy policy

This policy covers the current official ImgConvert desktop releases. Where a data practice differs by distribution channel, this policy identifies that channel specifically. It does not replace the privacy policies of Apple, Microsoft, GitHub, or your operating-system provider.

ImgConvert is a local image batch-conversion tool. We process data according to the principles of local-first operation and minimal collection.

Core commitments

  • Conversion, compression, thumbnail generation, and processing run on your device.
  • We do not upload or collect your images, file paths, clipboard content, or conversion results for us or a third party.
  • ImgConvert contains no advertising SDK, behavioral analytics SDK, third-party tracking, or account system.
  • The Mac App Store and Microsoft Store editions do not enable an in-app updater. Their software updates are delivered by the respective store.

Data, file access, and local storage

ImgConvert does not upload, collect, or transmit image contents, file names or paths, clipboard contents, conversion results, image metadata, device identifiers, hardware information, system logs, or usage behavior for image-conversion or analytics purposes.

The app accesses only input files authorized through the system file picker, the output directory you choose, and clipboard images when you actively choose clipboard import. It does not scan photo libraries, disks, or network locations in the background.

Conversion preferences, a custom output-directory path, temporary files, thumbnail caches, and result-cache records stay local. Result-cache records contain hashes and file sizes, not image bytes or file paths; you can disable result reuse in the app and remove local settings or caches yourself. In editions that allow a user-selected HEIC helper, that helper path may also be stored locally.

Apple platform access and HEIC decoding

The Mac App Store edition does not access Apple Music, your Apple Music library, or your Photos library. It does not request contacts, camera, microphone, or location access. When you actively select a HEIC file, it may use built-in macOS ImageIO to decode that selected file locally. It does not create HEIC output, bundle an external HEIC/HEVC codec, or discover third-party codec helpers in that edition.

Windows HEIC decoding

The Microsoft Store edition does not bundle external HEIC/HEVC codecs or automatically discover third-party helpers. Where Microsoft HEIF Image Extensions or HEVC Video Extensions are installed, Windows system interfaces may decode a selected HEIC file locally. ImgConvert does not create HEIC output.

Updates and third-party services

The Mac App Store and Microsoft Store editions do not use an in-app update channel. A separately configured direct-distribution build can contact GitHub Releases only after you choose to check for or install an update. That connection follows GitHub's privacy practices and does not upload your images or conversion data.

Apart from that optional, user-initiated direct-update connection, ImgConvert does not call third-party network services for app operation and includes no analytics, advertising, crash reporting, or remote-configuration services.

Metadata, children, updates, and contact

Output images do not preserve source metadata by default. Supported ICC, EXIF, XMP, or IPTC metadata is written only when you explicitly enable Preserve metadata. ImgConvert does not provide targeted content for children and does not actively collect personal information from any user.

If our data practices change, we will update this policy and its effective date before release. For support or privacy questions, use the ImgConvert issue tracker.

02 / 简体中文

隐私政策

本政策适用于当前 ImgConvert 的官方桌面版。若不同分发渠道的数据处理方式不同，本政策会明确标注对应渠道。本政策不替代 Apple、Microsoft、GitHub 或操作系统提供方各自的隐私政策。

ImgConvert 是一款在本机运行的图片批量转换工具。我们默认按“本地优先、最小收集”的原则处理数据。

核心承诺

  • 图片转换、压缩、缩略图生成和处理均在本机完成。
  • 不上传，也不会向我们或第三方收集你的图片、文件路径、剪贴板内容或转换结果。
  • 不包含广告 SDK、行为统计 SDK、第三方埋点或账号系统。
  • Mac App Store 和 Microsoft Store 版本均不启用应用内更新，软件更新由各自的应用商店提供。

数据、文件访问与本机存储

ImgConvert 不会为图片转换或分析目的上传、收集或向第三方传输图片内容、文件名或路径、剪贴板内容、转换结果、图片元数据、设备标识、硬件信息、系统日志或使用行为。

应用只会访问你通过系统文件选择器授权的输入文件、你选择的输出目录，以及你主动使用剪贴板导入功能时提供的剪贴板图片；不会后台扫描相册、硬盘或网络位置。

转换偏好、自定义输出目录路径、临时文件、缩略图缓存和结果缓存记录均保留在本机。结果缓存记录只包含哈希值和文件大小，不包含图片字节或文件路径；你可以在应用中关闭结果复用并自行删除本机设置或缓存。在允许用户选择 HEIC helper 的版本中，所选 helper 路径也可能保存在本机。

Apple 平台访问与 HEIC 解码

Mac App Store 版本不会访问 Apple Music、你的 Apple Music 资料库或照片图库，也不会请求通讯录、相机、麦克风或位置数据访问权限。当你主动选择 HEIC 文件时，应用可能通过 macOS 内置 ImageIO 在本机解码该文件。该版本不输出 HEIC，不捆绑外部 HEIC/HEVC 编解码器，也不发现第三方 codec helper。

Windows HEIC 解码

Microsoft Store 版本不捆绑外部 HEIC/HEVC 编解码器，也不自动发现第三方 helper。系统安装 Microsoft HEIF Image Extensions 或 HEVC Video Extensions 时，Windows 系统接口可能在本机解码用户选择的 HEIC 文件。ImgConvert 不输出 HEIC。

更新与第三方服务

Mac App Store 和 Microsoft Store 版本不使用应用内更新通道。单独配置的直发版本仅会在你主动检查或安装更新时连接 GitHub Releases；该连接受 GitHub 隐私政策约束，且不会上传你的图片或转换数据。

除上述可选、由用户主动触发的直发更新连接外，ImgConvert 不会为了应用运行调用第三方网络服务，也不包含分析、广告、崩溃报告或远程配置服务。

元数据、儿童、政策更新与联系

默认情况下，输出图片不会自动保留原图元数据。只有在你明确开启“保留元数据”选项时，应用才会写入受支持的 ICC、EXIF、XMP 或 IPTC 元数据。ImgConvert 不面向儿童提供定向内容，也不主动收集任何用户的个人信息。

如果隐私处理方式发生变化，我们会在发布受影响版本前更新本政策并同步修改生效日期。如需支持或对隐私政策有任何问题，请使用 ImgConvert issue tracker。
