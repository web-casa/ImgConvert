WINDOWS · PNG → AVIF

Windows 下 PNG 转 AVIF 的本地工具与操作方法

ImgConvert 可在 Windows 本机处理你主动选择的 PNG 文件或文件夹，并输出 AVIF；图片不上传到网页服务。

操作步骤

  1. 导入 PNG 文件或文件夹。
  2. 将输出格式设为 AVIF。
  3. 需要逐像素保留时开启无损压缩。
  4. 选择输出目录并开始转换。

使用提示

真无损 AVIF 可以保留像素，但文件不保证一定比源 PNG 更小。

常见问题

可将多个 PNG 放入同一任务队列。转换和压缩都在本机完成。
