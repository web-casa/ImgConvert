Windows 下如何批量压缩图片（PNG、JPEG、WebP、AVIF）？

ImgConvert 在 Windows 本机处理你主动选择的图片或文件夹，不上传图片到网页服务。

操作步骤

  1. 将文件或文件夹加入任务队列。
  2. 选择 JPEG、PNG、WebP 或 AVIF 输出格式。
  3. 按用途调整质量或无损模式。
  4. 确认目录，并按需开启“跳过更大输出”。

使用提示

压缩结果取决于图片内容、目标格式和编码设置，不能保证每张图片都会更小。

常见问题

可批量处理主动选择的文件或文件夹；整个流程在本机完成。
