Ubuntu 上如何为 WebP 图片进行本地无损压缩？

使用 ImgConvert 可将 WebP 保持为输出格式并开启无损模式，在 Ubuntu 本机重新编码图片而不上传到在线压缩器。

操作步骤

  1. 导入 WebP 文件或文件夹。
  2. 把目标格式保持为 WebP。
  3. 开启无损，并保留跳过更大输出。
  4. 选择输出目录并开始处理。

使用提示

无损 WebP 的目标是像素可逆，不保证每张图片都更小。

常见问题

质量 100 不等于真无损；如果候选输出更大，可使用跳过选项避免写入。
