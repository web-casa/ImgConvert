Linux 下如何在本地将 JPEG 转成 AVIF？

ImgConvert 在 Linux 本机将你主动选择的 JPEG/JPG 文件或文件夹输出为 AVIF，不需要在线转换服务。

操作步骤

  1. 导入 JPEG/JPG 文件或文件夹。
  2. 将输出格式设为 AVIF。
  3. 根据用途调整质量。
  4. 确认目录，并按需启用跳过更大输出。

使用提示

JPEG 已是有损来源；转成无损 AVIF 无法恢复过去编码中丢失的细节。

常见问题

可批量转换 JPEG/JPG；处理只在本机完成。
