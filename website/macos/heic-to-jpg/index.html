macOS 下如何将 HEIC 转成 JPG？

如果 macOS 能通过系统 ImageIO 读取该 HEIC 或 HEIF 文件，ImgConvert 可在本机将它转换为 JPEG/JPG。

操作步骤

  1. 导入 HEIC 或 HEIF 图片。
  2. 将目标格式设为 JPEG。
  3. 按用途选择 JPEG 质量与元数据选项。
  4. 选择输出目录并开始转换。

使用提示

HEIC 是平台能力支持的只读导入，ImgConvert 当前不导出 HEIC。

常见问题

可将多个 HEIC 文件放入同一队列，支持的文件会在 macOS 本机读取。
