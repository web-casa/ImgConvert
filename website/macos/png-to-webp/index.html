MACOS · PNG → WEBP

macOS 下如何在本地将 PNG 转成 WebP？

ImgConvert 在 macOS 本机读取你主动选择的 PNG 文件或文件夹，并把 WebP 写入你选择的目录。

操作步骤

  1. 导入 PNG 文件或文件夹。
  2. 将输出格式设为 WebP。
  3. 按交付需求选择质量或无损模式。
  4. 确认目录并开始转换。

使用提示

无损 WebP 关注可逆像素，并不保证每张 PNG 都比原图小。

常见问题

多张 PNG 可在一个队列中处理；转换不需要上传原图。
