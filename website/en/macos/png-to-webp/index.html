How to convert PNG to WebP locally on macOS

ImgConvert reads the PNG files or folders you intentionally select on macOS and writes WebP to a directory you choose.

Steps

  1. Import PNG files or a folder.
  2. Set WebP as the output format.
  3. Choose quality or lossless mode for the delivery need.
  4. Confirm the directory and convert.

Notes

Lossless WebP targets reversible pixels; it does not promise that every PNG will be smaller than its source.

Common question

Multiple PNG images can be processed in one queue, with no original-image upload.
