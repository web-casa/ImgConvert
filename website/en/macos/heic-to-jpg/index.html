How to convert HEIC to JPG on macOS

When macOS can read a HEIC or HEIF file through its system ImageIO support, ImgConvert can convert it to JPEG/JPG locally.

Steps

  1. Import HEIC or HEIF images.
  2. Choose JPEG as the output format.
  3. Set JPEG quality and metadata choices for the intended use.
  4. Choose the output directory and start conversion.

Notes

HEIC is a platform-capability read-only import. ImgConvert does not currently export HEIC.

Common questions

Multiple HEIC files can share one queue, and supported files are read locally by macOS.
