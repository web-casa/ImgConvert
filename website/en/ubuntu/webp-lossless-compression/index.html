How to compress WebP losslessly on Ubuntu

Keep WebP as the output format, enable lossless mode, and re-encode images locally on Ubuntu instead of sending them to an online compressor.

Steps

  1. Import WebP files or a folder.
  2. Keep WebP as the output format.
  3. Enable lossless and keep Skip larger outputs on.
  4. Choose the output directory and process the batch.

Notes

Lossless WebP targets reversible pixels and cannot guarantee a smaller result for every image.

Common questions

Quality 100 is not true lossless mode. The skip option can avoid writing a larger candidate output.
