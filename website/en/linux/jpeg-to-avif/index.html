How to convert JPEG to AVIF locally on Linux

ImgConvert writes AVIF from JPEG/JPG files or folders you intentionally select on Linux, without an online conversion service.

Steps

  1. Import JPEG/JPG files or a folder.
  2. Set AVIF as the output format.
  3. Adjust quality for the delivery need.
  4. Confirm the directory and enable Skip larger outputs when useful.

Notes

JPEG is already lossy. Converting it to lossless AVIF cannot recover detail lost in an earlier encoding step.

Common question

JPEG/JPG can be batch-converted, entirely on your device.
