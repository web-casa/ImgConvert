How to convert PNG to AVIF locally on Windows

ImgConvert processes the PNG files or folders you choose on Windows and writes AVIF output without sending images to a web service.

Steps

  1. Import PNG files or a folder.
  2. Set AVIF as the output format.
  3. Enable lossless compression when pixels must be preserved.
  4. Choose the output directory and convert.

Notes

True lossless AVIF preserves pixels, but does not guarantee a file smaller than the source PNG.

Common questions

Multiple PNG files can share one queue. Conversion and compression happen on the device.
