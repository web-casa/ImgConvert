How to batch-compress images on Windows

ImgConvert processes the images or folders you intentionally choose on your Windows device instead of uploading them to a web service.

Steps

  1. Add files or a folder to the task queue.
  2. Choose JPEG, PNG, WebP, or AVIF as the output format.
  3. Adjust quality or lossless mode for the job.
  4. Confirm the directory and keep Skip larger outputs on when useful.

Notes

Results depend on image content, target format, and encoder settings; no setting can guarantee every image will be smaller.

Common question

You can process intentionally selected files or folders in a batch, entirely locally.
