PRIVACY POLICY

Privacy, in plain language.

ImgConvert offers desktop releases and an in-browser local Web app. Both follow local-first operation and minimal collection by default.

Core commitments

Desktop runs locally and Web runs in browser workers. Images, paths, clipboard content, and conversion results are not uploaded or collected.

File access and permissions

The app accesses only input files, output folders, and clipboard images that you actively choose. It does not scan photo libraries, disks, or network locations in the background.
