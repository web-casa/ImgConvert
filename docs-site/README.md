# ImgConvert Docs Site

Fumadocs + Next.js documentation site for ImgConvert.

The site is intentionally split by reader task:

- install and verify GitHub Release packages
- use the desktop app
- troubleshoot Linux/AppImage/HEIC/updater issues
- maintain release and quality commands
- explain architecture, format support, HEIC policy, and development guardrails

## Commands

```bash
pnpm run dev
pnpm run build
pnpm run check
```

From the repository root:

```bash
pnpm run docs:web:dev
pnpm run docs:web:build
pnpm run docs:web:check
```
