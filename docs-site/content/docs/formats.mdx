## 支持矩阵

| 格式 | 读取 | 写入 | 说明 |
| --- | --- | --- | --- |
| JPEG | 是 | 是 | 支持质量参数、metadata 保留/剥离、EXIF orientation 真旋正 |
| PNG | 是 | 是 | 支持 8-bit/16-bit 路径和无损输出 |
| WebP | 是 | 是 | 支持有损/无损、质量策略、DPI probe |
| AVIF | 是 | 是 | 支持有损与真无损路径，自动质量仍保持保守 |
| SVG | 是 | 否 | 仅本地栅格化，使用声明画布；不读取外部或 data-URI 图像资源 |
| GIF | 是（仅静态） | 否 | 动图 GIF 明确拒绝，避免静默丢失帧 |
| BMP | 是 | 否 | 受与其他栅格输入一致的尺寸/分配上限保护 |
| HEIC | 可选 | 否 | 仅 decode-only，可由系统或 helper 提供 |

## 压缩策略

- `skip-if-larger`：输出变大时跳过写入。
- 多候选取最小：在安全预算内比较候选输出。
- 自动质量：当前主要面向 JPEG/WebP。
- 代际损失防护：避免重复压缩造成明显质量下降。

## 元数据

当前支持 ICC、EXIF、XMP、IPTC 的保留或剥离策略。JPEG/PNG 的 EXIF orientation 会真旋正并改写为 1，避免查看器二次旋转。
