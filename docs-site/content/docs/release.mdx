## 发布前硬闸门

```bash
pnpm run release:readiness:github:ready
```

这个命令是本地只读检查。任何第一期范围内的 artifact、updater signature、`latest.json` 或前置条件缺失都会失败。

## 远端 smoke

```bash
pnpm run release:updater:smoke -- --repo=yeagoo/imgconvert --tag=v0.1.1 --platform=linux-x86_64 --no-run
pnpm run release:updater:smoke -- --repo=yeagoo/imgconvert --tag=v0.1.1 --platform=linux-aarch64 --no-run
```

`--no-run` 会下载远端 `latest.json`、AppImage 和 `.sig`，校验 manifest 签名一致性，但不在当前机器执行不同架构的 AppImage。
