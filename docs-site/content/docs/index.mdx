ImgConvert 是一个 **Tauri 2 + Svelte 5 + Rust 图像核心** 的本地优先图片批量转换工具。当前第一期发布范围已经收敛为 GitHub Releases，不提交任何商店。

## 当前状态

- 第一批发布渠道：GitHub Releases。
- 第一批 Linux 资产：`.deb`、`.rpm`、AppImage、AppImage `.sig`、`latest.json`、`SHA256SUMS`。
- 输出格式：JPEG、PNG、WebP、AVIF；另支持 SVG、静态 GIF、BMP 导入。
- HEIC：主程序不内置，按平台系统能力或外部 helper/extension 走可选导入。
- 许可证：主程序 Apache-2.0，主依赖树禁止 GPL、AGPL、LGPL。

## 本地开发

```bash
pnpm install
pnpm run dev
pnpm run tauri dev
```

文档站开发：

```bash
pnpm run docs:web:dev
```
