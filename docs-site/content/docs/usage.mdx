---
title: 使用
description: ImgConvert 的批量导入、格式选择、压缩和元数据选项。
---

ImgConvert 的主流程是：导入图片，选择目标格式与压缩策略，确认输出位置，然后开始批量转换。

## 导入

支持的导入方式：

- 拖拽图片或目录到窗口。
- 点击选择文件导入。
- 选择目录并递归导入。
- 从剪贴板导入图片。

内置输入格式为 JPEG、PNG、WebP、AVIF、SVG、静态 GIF 和 BMP。SVG 会本地栅格化；动画 GIF 会显示明确错误，绝不会自动只取第一帧。HEIC 仍取决于平台能力或可选 helper。

导入后队列会异步读取基础信息和缩略图。超大图会进入内存预算控制，转换并发可能自动降低。

## 选择格式

目标格式由当前后端能力矩阵驱动。主程序内置输出：

- JPEG
- PNG
- WebP
- AVIF

HEIC 仅作为可选输入，不提供 HEIC 输出。系统或 helper 不可用时，界面会把 HEIC 能力标为不可用，并在诊断里给出原因。

## 压缩选项

常用策略：

- `skip-if-larger`：可选的压缩策略，仅在转换结果小于原图时才写入。默认关闭；如果因兼容性必须得到指定格式，请保持关闭。
- 代际损失防护：可选策略，对收益不足的有损转有损重编码跳过写入。为保证格式转换，默认关闭。
- 自动质量：优先用于 JPEG/WebP，在可接受质量下寻找更小输出。
- 多候选取最小：在预算内比较多个候选结果。
- AVIF 真无损：只在能力矩阵明确支持时暴露。

如果目标是“减小体积”，优先使用 WebP 或 AVIF；如果目标是“兼容性”，优先使用 JPEG 或 PNG。

## 元数据与色彩

ImgConvert 默认把元数据当成用户资产处理，不把它当作可随意丢弃的附属信息。

当前支持：

- EXIF orientation 真旋正，并把 orientation 改写为 1。
- ICC profile 保留或按策略转换。
- EXIF、XMP、IPTC 的保留或剥离。
- Display P3 / sRGB 相关路径的测试护栏。

如果你要发布到网页，并且不希望暴露拍摄设备、定位或编辑软件信息，可以关闭 metadata 保留。

## 批量转换

转换时会显示每个文件的状态、进度、失败原因和汇总。取消操作会尽量停止未开始任务；已经进入 codec 内部的单张图片会在当前转换点结束后回收。

失败项不会阻塞整个队列。完成后可以根据失败原因处理文件权限、格式能力或损坏输入，再重新导入。

## 输出建议

建议把输出目录设置到独立文件夹，避免与原图混放。做批量压缩或格式迁移前，保留原始图片备份。
